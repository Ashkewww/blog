# Ayush's Archives 🗃️

**Ayush's Archives** is my personal blog where I document thoughts, reflections, and creative writings. Built with **Next.js** and styled using **Tailwind CSS**, the content is managed privately using **Wisp CMS**.

This is a hobby project I created for myself — not intended as a template, product, or public-facing platform.

[📂 GitHub Repository](https://github.com/Ashkewww/blog)

---

## Tech Stack

- **Frontend**: [Next.js](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **CMS**: [Wisp](https://wisp.readme.io/)
- **Hosting**: [Vercel](https://vercel.com/)

---

## About This Project

I made this project as a quiet corner on the web for my own thoughts and ideas — part journal, part creative outlet. Everything here is personal and curated privately through Wisp.

There are no feature pages, no public content management, and no plans to open this for wider use. It’s purely for me.
